# Employee Payroll System

A Python-based payroll system that calculates employee salaries, allowances, deductions, and net salary.

## Features
- Store employee details
- Calculate HRA
- Calculate DA
- Calculate PF deduction
- Calculate gross salary
- Calculate net salary

## Technologies
- Python
- Lists
- Dictionaries
- Functions
- Mathematical calculations

## How to Run
python employee_payroll.py
